## About Me

I am a systems and backend engineer focused on building robust architectures, low-level software, intelligent AI systems, and connected robotics. My work spans the stack from bare-metal hardware and operating system internals up to distributed APIs, multimodal vision models, and agentic workflows.

### Core Competencies & Skills

- **Artificial Intelligence & Vision Models**: Designing and implementing Retrieval-Augmented Generation (RAG) pipelines, neural network architectures, agentic AI workflows, and multimodal vision engines (facial recognition, semantic text-to-image search) using PyTorch, OpenCV, InsightFace, and LLM orchestration.
- **Operating Systems & Low-Level Programming**: Writing efficient systems software in C, exploring OS kernel mechanisms (virtual memory paging, interrupts, and syscalls), and debugging low-level code using Linux tooling, GDB, and QEMU.
- **Backend Development & Distributed Systems**: Architecting scalable, low-latency REST and WebSocket APIs, asynchronous event processing, and data persistence layers across PostgreSQL, SQLite, and Redis.
- **Robotics & Embedded IoT**: Developing embedded firmware for ESP32 microcontrollers, handling sensor telemetry streams, edge computer vision processing, and motor control integration for autonomous rover systems.
- **Linux & Systems Tooling**: Native Linux development workflows, shell scripting, POSIX system programming, Docker containerization, and Git.

### 👁️ [The-Eyes](https://github.com/Rishikeshn2007/The-eyes)
**Multimodal Photo Indexing & Hybrid Search Engine**

> *A lightweight, local multimodal photo indexing and retrieval engine combining facial recognition, semantic text-to-image search, and hybrid retrieval with embedded SQLite vector storage.*

- **Multi-Modal Retrieval Pipeline**: Automated face detection and extraction via InsightFace (`buffalo_l`), semantic text-to-image search via Jina CLIP v2, and hybrid filtering combining identity with scene queries.
- **Embedded Vector Storage**: High-dimensional vector embeddings stored directly in SQLite without requiring external vector database overhead.
- **Full-Stack Performance**: Fast, asynchronous FastAPI backend paired with an intuitive React interface for indexing and visual querying.

### 🎓 [Study Assistant](https://github.com/Rishikeshn2007/Study_assistent)
**AI-Powered Full-Stack Learning Platform**

> *A modern, full-stack AI study platform with ChatGPT-style chat, Google OAuth, persistent Firestore sessions, and Qwen LLM integration.*

- **Full-Stack Architecture**: Next.js 16 (React 19 + TypeScript + Tailwind CSS) frontend paired with a stateless FastAPI backend and Qwen LLM API for intelligent responses.
- **Authentication & Persistence**: Firebase Google OAuth with Firebase Firestore for per-user, per-session chat history with rename, delete, and regenerate actions.
- **General & RAG Modes**: ChatGPT-style interface with Markdown rendering, syntax-highlighted code blocks, and extensible RAG mode for document-grounded answers.
